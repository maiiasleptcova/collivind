A summary is one memory that sums up a working session (or a topic) as a list of dated facts, linked to the detail memories it covers. Recall reads summaries first, so an agent gets the gist before the details.

Agents write them: once a session has saved enough memories, the next checkpoint asks the agent to call collivind_summarize. You can also write one from a terminal: collivind summarize --session <id> prints a session's memories to sum up, and --text saves the summary.
