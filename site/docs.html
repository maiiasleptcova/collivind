How Collivind works

The overview is below. The full documentation is the README on GitHub, and each topic here links to its section there, so there is one copy to keep current.

The pieces

Hooks are short commands your agent runs at fixed moments: session start, each prompt, after responses, before compaction. They search memory and add what matches to the context, or ask the agent to save. A hook cannot write memories itself, because pulling knowledge out of a conversation needs the agent's model; the agent does it through the MCP tools.

The core library is the same in every mode; only the storage backends change. docker mode uses Qdrant, Neo4j and an embedding and reranking service in containers. embedded mode uses SQLite for both stores and loads the embedding and reranking models locally, kept warm by a small background process. remote mode points at services you run yourself.
